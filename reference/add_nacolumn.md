# Filling missed columns with NAs

If columns of `y` are missed in `x`, the later gets these columns filled
with `NA` values.

## Usage

``` r
add_nacolumn(x, y)
```

## Arguments

- x:

  (`data.frame`) The data frame to be compared.

- y:

  (`data.frame`) The data frame used as reference.

## Value

A `data.frame`.
