# List of vascular plants from East Africa

Example of an incomplete taxonomic list including taxa recorded in East
Africa.

## Usage

``` r
Easplist
```

## Format

An object of class
[taxlist](https://docs.ropensci.org/taxlist/reference/taxlist-class.md).

## Source

[African Plant Database](https://africanplantdatabase.ch/),
[SWEA-Dataveg](http://www.givd.info/ID/AF-00-006).

## Details

This list is a subset of the taxonomic list implemented in the database
[SWEA-Dataveg](http://www.givd.info/ID/AF-00-006). Since this list is
being complemented regarding stored vegetation plots, it is an
incomplete list.
